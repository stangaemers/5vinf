# Frencken Webtemplate

Deze omgeving is bedoeld voor informatica-opdrachten met HTML, CSS, PHP, SQL, JSON en XML.

## Website openen

Ga onderin naar het tabblad **Poorten**.

Klik bij poort **8000** op het doorgestuurde adres.

## phpMyAdmin openen

Ga onderin naar het tabblad **Poorten**.

Klik bij poort **8080** op het doorgestuurde adres.

Inloggen:

- gebruiker: root
- wachtwoord: root

## Bestanden uploaden

Sleep bestanden naar de juiste map in de bestandsverkenner.

Bijvoorbeeld:

- afbeeldingen in `public/afbeeldingen`
- JSON/XML in `public/data`
- uploads via PHP in `public/uploads`
